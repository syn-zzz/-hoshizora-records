# 検品チェックリスト：ほしぞらレコード デモサイト

工程6（検品）で使う。DESIGN.md・CONTENTS.md・PLAN.md の決まりから作成。「受注後」の項目は本番公開のときに確認する。

## 表示・レスポンシブ

- [ ] 375px／768px／1280px で崩れない。横スクロールが出ない
- [ ] スマホ固定バーは 599px 以下だけに表示。フォーム入力中は隠れる
- [ ] 入荷カード：スマホ2列／PC3列
- [ ] ヒーロー写真の比率：スマホ 4:5／PC 16:9（写真を使う場合）
- [ ] ヘッダーは高さ 72px のまま追従する（スクロールで高さが変わらない）。スクロールでがたつかない
- [ ] 実機で確認（iPhone の Safari、Android の Chrome。手元にあれば）

## 速度

- [ ] Lighthouse モバイル Performance 90以上、LCP 2.5秒以内、CLS 0.1以下
- [ ] ヒーロー：画像は合計200KB以内、JSは50KB以内、動画なし
- [ ] 画像はすべて WebP。width と height を指定。ファーストビュー以外は loading="lazy"
- [ ] Google Fonts は2書体だけ（Shippori Mincho B1／Zen Kaku Gothic New）、display=swap

## デザイン（DESIGN.md）

- [ ] 色は CSS変数（--hr-）経由。カラーコードを直接書いていない
- [ ] 基本の背景は白、生成りは要所だけ（Design.md 4章の背景リズム）。朱以外の色を足していない
- [ ] 主要ボタンは1画面に1つ（ヘッダーの「買取を相談する」は副ボタン、トップの最初の画面の主要は「行き方を見る」）
- [ ] 星（✦）は1画面に3つまで
- [ ] 回転するレコード・パララックス・自動再生スライダーがない
- [ ] 独自CSSのクラス名が hr- で始まる

## アクセシビリティ

- [ ] 画像の alt に写っている物を具体的に書いている。装飾画像は alt=""
- [ ] フリー素材の alt に「ほしぞらレコードの店内」など事実と違うことを書いていない
- [ ] コントラスト：文字 4.5:1 以上、入力欄の枠など文字以外の部品 3:1 以上
- [ ] キーボードだけで全ページを操作できる。フォーカス表示が見える
- [ ] h1 は1ページに1つ。見出しが h1 → h2 → h3 の順
- [ ] 色だけで情報を伝えていない（営業中バッジ・エラー・必須表示に文字がある）
- [ ] 動きを減らす設定（prefers-reduced-motion）でアニメーションが止まる
- [ ] タップ領域は 44×44px 以上
- [ ] 地図の近くに住所を文字で書いている

## 内容（CONTENTS.md）

- [ ] {{ }} が残っていない
- [ ] 架空データに【デモ】表記がある。フッターにデモ表記がある
- [ ] 【要確認】の項目はダミー表記になっている
- [ ] 電話（tel:）・メール・住所・営業時間が正しい
- [ ] 営業中バッジ：火・水は「本日定休」、木〜月の 10:30 前と 18:00 以降は「営業時間外」、営業時間内は何も出ない（端末の日時を変えて確認）。札が横に伸びていない
- [ ] リンク切れがない（ナビ・ボタン・フッターのすべて）
- [ ] 実在アルバムのジャケット、Instagram や他サイトの写真を使っていない

## 画像・ライセンス

- [ ] 外部URLへの直接リンクがない（すべてメディアライブラリ）
- [ ] credits.md に出典とライセンスを記録している
- [ ] 人物が写った素材を「店主」「お客様」として見せていない

## SEO・メタ

- [ ] title、meta description、og:title、og:description、og:image がある
- [ ] favicon がある
- [ ] デモ中は noindex（WordPress の表示設定でもチェック）

## フォーム（Contact Form 7）

- [ ] 必須項目が空のときにエラーが出る（Error色＋文字＋「!」アイコン）
- [ ] /contact/?type=buyback で「買取の相談」が選ばれている
- [ ] 送信すると、管理者への通知と自動返信が Mailpit に届く
- [ ] 送信内容が Flamingo に保存される
- [ ] スパム対策が有効
- [ ] プライバシーポリシーへの同意がないと送信できない

## WordPress

- [ ] WP_DEBUG を true にしてもエラーや警告が出ない
- [ ] 管理画面で入荷記事を追加すると、トップの新着に反映される
- [ ] ブロックで編集する箇所を変更しても、デザインが崩れない
- [ ] バックアップから1回復元してみて、元に戻せることを確認した
- [ ] 使っていないプラグインがない
- [ ] Novamira の AI 機能を作業後にオフにしている

## 公開時（受注後）

- [ ] HTTPS になっている（http から https へ転送される、混在コンテンツがない）
- [ ] noindex を外した。【デモ】データとデモ表記を消した
- [ ] 古物商許可番号を記載した
- [ ] 本番の写真の alt を実際の内容に書き直した
- [ ] WordPress・テーマ・プラグインが最新。管理者パスワードが強い
- [ ] Novamira を本番では削除、または AI 機能をオフにしている
- [ ] Search Console 登録、サイトマップ送信、構造化データ（LocalBusiness）
- [ ] Googleビジネスプロフィールの営業時間と一致している
