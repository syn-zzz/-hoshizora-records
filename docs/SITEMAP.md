## 1. サイトの目的

| 段階 | 目的 | 成功の目安 |
| --- | --- | --- |
| デモ（今） | 店主さんに見せて、リニューアルを任せてもらう | 「このサイトなら来店が増えそう」「自分でも更新できそう」と思ってもらえる |
| 本番（受注後） | ① 夢見市観光のついでに来店してもらう ② 買取の相談を受ける | 「行き方を見る」のクリック、電話タップ、買取相談フォームの送信 |

サイト全体で一番大事なこと：**行き方と営業時間がすぐわかること**（店が2階にあり、通りから見つけにくいため）

## 4. 全ページ共通の部品

* ヘッダー：文字ロゴ「ほしぞらレコード」＋星／ナビ（ホーム・はじめての方へ・入荷情報・営業日・アクセス・お問い合わせ。2026-11-08 変更）／ボタン「買取を相談する」／ナビの下に営業時間。買取ページへはボタンとフッターから
* フッター：店名・住所・営業時間・古物商許可番号【要確認】・Instagram・プライバシーポリシー・デモ表記・コピーライト
* スマホ固定バー（〜599px）：電話する／行き方／買取相談
* パンくずリスト：下層ページの h1 の上（例：トップ ＞ 買取）

### 決定：ヘッダーの「買取を相談する」は副ボタン（2026-11-06）

DESIGN.md は「主要ボタンは1画面に1つ」。ヘッダーのボタンは枠線だけの副ボタンにして、各ページの主要ボタン（トップは「行き方を見る」）を目立たせる。来店がサイト最大の目的なので、最初の画面の主役を行き方にそろえる。

## 5. 入荷情報の管理（WordPress の投稿）

| 項目 | 入れ方 | 例 |
| --- | --- | --- |
| タイトル | 投稿タイトル | Night Harbor / Slow Tide |
| ジャンル | カテゴリ（1つだけ選ぶ） | ROCK／JAZZ／SOUL／FOLK／邦楽／CITY POP／PSYCHE／MIX |
| アーティスト名・作品名 | カスタムフィールド（ACF 無料版） | Night Harbor ／ Slow Tide |
| 価格 | カスタムフィールド（数値） | 2800 → 表示は ¥2,800 |
| タグ | タグ | レア盤／まとめて入荷／100円コーナー |
| 売り切れ | カスタムフィールド（チェック） | オンで写真に「SOLD」 |
| 写真 | アイキャッチ画像（1:1） | デモはプレースホルダー |
| 本文 | 本文（ブロック） | 盤の状態、聴きどころなど |

* トップ：最新6件を表示
* 一覧：1ページ12件、ジャンルで絞り込み、ページ送り
* 店主さんがスマホからでも投稿できる項目数にとどめる

## 6. 検索・共有の設定

* 各ページの title と meta description は CONTENTS.md・CONTENTS_PAGES.md に書く
* title の型：「ページ名｜ほしぞらレコード（夢見市の中古レコード店）」。トップだけ CONTENTS.md の title
* og:image：1200×630 の画像を1枚（デモはロゴと星の画像）
* デモ中は全ページ noindex

## 7. デモで作らないもの（受注後に検討）

* ネット通販・在庫検索（店頭販売のみの前提）
* お客様の声の専用ページ（トップの2件だけ）
* 英語ページ（観光客向けに需要があれば受注後に提案）
* ブログ・コラム（「はじめての方へ」で代わりにする）
